# Система аутентификации и авторизации

## Обзор

В приложение добавлена полная система регистрации и авторизации пользователей с использованием базы данных Access.

## Функциональность

### 🔐 Аутентификация
- **Вход в систему** - авторизация по имени пользователя и паролю
- **Регистрация** - создание новых пользователей
- **Выход из системы** - безопасное завершение сессии
- **Хеширование паролей** - пароли хранятся в зашифрованном виде

### 👤 Управление пользователями
- **Роли пользователей** - обычные пользователи и администраторы
- **Информация о пользователе** - отображение текущего пользователя в интерфейсе
- **Безопасность** - проверка уникальности имени пользователя и email

## Структура базы данных

### Таблица Users
```sql
CREATE TABLE Users (
    Id AUTOINCREMENT PRIMARY KEY,
    Username TEXT(50) NOT NULL UNIQUE,
    Email TEXT(100) NOT NULL UNIQUE,
    PasswordHash TEXT(255) NOT NULL,
    FirstName TEXT(50),
    LastName TEXT(50),
    Role TEXT(20) DEFAULT 'User',
    IsActive YESNO DEFAULT True,
    CreatedDate DATETIME DEFAULT Now(),
    LastLoginDate DATETIME,
    UpdatedDate DATETIME
)
```

## Использование

### Первый запуск
1. При первом запуске автоматически создается администратор по умолчанию:
   - **Имя пользователя:** `admin`
   - **Пароль:** `admin123`
   - **Роль:** Администратор

### Регистрация нового пользователя
1. Нажмите кнопку "Регистрация" в окне входа
2. Заполните обязательные поля:
   - Имя пользователя (минимум 3 символа)
   - Email (корректный формат)
   - Пароль (минимум 6 символов)
   - Подтверждение пароля
3. Опционально заполните имя и фамилию
4. Нажмите "Зарегистрироваться"

### Вход в систему
1. Введите имя пользователя и пароль
2. Нажмите "Войти"
3. При успешной авторизации откроется главное окно приложения

### Выход из системы
1. Нажмите кнопку "Выйти" в правом верхнем углу главного окна
2. Подтвердите выход
3. Откроется окно входа в систему

## Безопасность

### Хеширование паролей
- Пароли хешируются с использованием SHA256
- Добавлена соль для дополнительной безопасности
- Пароли никогда не хранятся в открытом виде

### Валидация данных
- Проверка уникальности имени пользователя и email
- Валидация формата email
- Проверка минимальной длины пароля
- Подтверждение пароля при регистрации

## Технические детали

### Сервисы
- **AuthenticationService** - основной сервис аутентификации
- **User** - модель пользователя
- **LoginWindow** - окно входа
- **RegisterWindow** - окно регистрации

### Интеграция
- Система полностью интегрирована с существующим приложением
- Автоматическое создание таблицы пользователей при первом запуске
- Обновленный интерфейс с информацией о текущем пользователе

## Роли пользователей

### User (Обычный пользователь)
- Доступ ко всем функциям приложения
- Может просматривать, добавлять, редактировать и удалять записи

### Admin (Администратор)
- Все права обычного пользователя
- Дополнительные административные функции (при необходимости)

## Устранение неполадок

### Проблемы с входом
1. Проверьте правильность имени пользователя и пароля
2. Убедитесь, что пользователь активен (IsActive = True)
3. Проверьте подключение к базе данных

### Проблемы с регистрацией
1. Убедитесь, что имя пользователя уникально
2. Проверьте корректность email адреса
3. Пароль должен содержать минимум 6 символов
4. Пароли должны совпадать

### Сброс пароля администратора
Если забыли пароль администратора, можно:
1. Открыть базу данных Access
2. Найти таблицу Users
3. Удалить или изменить запись администратора
4. При следующем запуске будет создан новый администратор по умолчанию
